🔮 第一步：起卦

点击 「摇卦」 按钮，系统会模拟三枚铜钱投掷。

  • 每次摇卦生成一爻，共摇 6 次，从下往上排列
  • ⚊ 代表阳爻，⚋ 代表阴爻
  • 出现 ○（老阳）或 ×（老阴）表示动爻
💡 摇卦前请静心凝神，心中默念所问之事

📜 第二步：排盘

六爻摇满后，点击 「完卦」，系统自动识别本卦和变卦。

  • 本卦：六爻摇出的初始卦象
  • 变卦：动爻变化后的卦象
  • 卦象下方会显示 世应 位置和 六亲
💡 点击 「重起」 可重新开始

🧠 第三步：AI释卦

点击 「释卦」 按钮，AI将以《增删卜易》理论为您解读。

  • 支持 千问旗舰（默认主力）和 千问备选（qwen3.7-flash）两种模型
  • 建议在起卦页面 填写所问之事，帮助AI精准分析
  • AI会分析用神、世应、五行生克，给出结论
💡 释卦结果仅供参考，决策还需理性判断

📚 所问之事 · 用户字典

本系统以《增删卜易》门目为宗，只认识下列固定的事情词。所问之事须用词贴近下表，方能按专门门类、依古法取用神精准断卦；世间百态岂能全揽，请勿自造词。

  • 婚姻（男取妻财 · 女取官鬼）：婚姻 · 嫁 · 娶
  • 学业（用神父母 · 读书问学）：上学 · 考试 · 进修
  • 功名（用神官鬼 · 升选科考在任）：功名 · 仕途 · 升职 · 求职 · 前程
  • 求财（用神妻财 · 贸易买卖）：财运 · 生意 · 股票 · 投资 · 买卖 · 交易 · 开张
  • 疾病（用神官鬼 · 延医病源）：疾病 · 康复 · 求医 · 治病
  • 出行（用神父母 · 舟行远门）：出行 · 旅游 · 出差
  • 行人归期（用神子孙 · 走失归期）：归期
  • 诉讼（用神官鬼 · 兴词防非）：诉讼 · 官司
  • 失物（用神妻财 · 遗失贼盗）：失物 · 遗失 · 丢失
  • 子嗣胎孕（用神子孙 · 产期求子）：怀孕 · 求子 · 生子 · 得子 · 子女 · 子孙
  • 家宅迁移（用神父母 · 盖造迁居）：住宅 · 搬家 · 买房 · 建房 · 风水 · 装修
  • 终身财福（用神妻财 · 身命）：终身 · 命运 · 财福

📌 考试 / 学业两分：单写"考试"二字默认归学业（用神父母），指上学、进修、在校期间考试；考录、晋升等仕途之事属功名（用神官鬼），请直接选用"功名 / 求职 / 前程"等标准词。功名之事请勿写"考试"二字，以免误归父母。
⚠ 现代词不入系统：公务员、公考、考公、职位、科考等现代表述不被系统固化词识别，输入后将按"所问之事用词不规范，只能通解"处理。问仕途功名，请用"功名 / 求职 / 前程"；问考试入学，请用"考试 / 上学 / 进修"。
📌 此卦择吉：点此按钮时，系统据所问之事映射黄历宜忌事项（嫁娶 / 交易 / 入学 / 求医 / 出行 / 祭祀 / 置产）查吉日。黄历本不严谨，故入口须用上表标准词，方能正确映射。
⚠ 用词不规范（自造词或过于口语化），系统匹配不到专门门类，将回复：「所问之事用词不规范，只能通解」——即按六爻常理泛论，不作专门断语，用神亦按所问泛取。请就近归入上表某类，或改用标准词。

📐 专业附录：断卦评分规则

综合结论徽标（吉 / 中 / 凶）由系统断卦引擎按七步断卦链逐条权衡计分得出。评分只作引擎权衡记录（内部逻辑权重之和），非求卦者所读断语；专业人员可依下表复核引擎取舍是否符合《增删卜易》古法。

计分方式（P1 权重：用神为尊）：按《增删卜易》"用神者，六爻之枢机"，评分分三等权重——用神本体一等（±2），用神假空二等（±1），世应忌仇卦象三等（±1）；察门类不计分。起始 0 分，全部规则计毕得总分。

  • 综合结论判定（五档）：总分 ≥ +3 → 大吉；+1 ～ +2 → 吉；= 0 → 中；-2 ～ -1 → 小凶；≤ -3 → 凶。分级以评分拉开档次，警示适度、不伤人。用神受制（月破/真空）单条即 -2，主凶，正合"用神月破如枯木无根"。

七步规则与加减分（一等 ±2 / 二等 ±1 / 三等 ±1）：

  • 察旺衰（用神·一等）：旺衰评分正 → +2；负 → -2；用神月破 → -2；用神真空 → -2；用神假空（旬空非真空）→ -1。
  • 观动静（用神·一等）：动而化进神 → +2；动而回头生 → +2；动而化退 / 回头克 / 化墓 / 化绝 / 化破 → -2；用神动散 → -2；动而化空、无特殊 → 不计。
  • 审世应（三等）：世应相合 → +1；用神持世 → +1；世应相冲 → -1；世爻月破 → -1。
  • 看忌仇元神（三等）：忌神无力 → +1；原神得力 → +1；忌神有力 → -1；仇神有力 → -1；原神旬空或伏藏 → -1。
  • 察卦象（三等）：六合卦 → +1；六冲卦 → -1；反吟 → -1；伏吟 → -1；用神入墓 → -1；用神临绝 → -1。
  • 察门类（知识库命中时）：并入断法要点，不计分。

理论边界与互斥：

  • 理论上限约 +9（用神旺相 +2、化进 +2、世应合、持世、忌神无力、原神得力、六合同时命中，极罕见）。
  • 理论下限约 -20（用神休囚 -2、月破 -2、真空 -2、化破/化墓 -2、动散 -2、世应冲、世爻月破、忌神有力、仇神有力、原神空藏、六冲、反吟或伏吟、入墓、临绝同时命中，极罕见）。
  • 常见卦象实际多在 -12 ～ +6 之间；多对规则天然互斥（六冲与六合、反吟与伏吟、化进与化退、真空与假空等），故两端极值难达。因用神加权，用神旺相之卦分数普遍上移、用神受制之卦分数下探，吉凶更贴原著"用神为尊"。
🔬 复核方法：展开断卦面板中的「断卦依据链（七步）」，逐条对照上表——每条"决句 + 结论 + 依据"对应一个加权项（用神本体 ±2 / 其余 ±1），总分即徽标所显评分。

📅 专业附录：应期裁决规则（P0-3）

应期由"应期引擎"依《增删卜易》"应期总注"法则推算：用神旬空→出空、月破→出月实破、入墓→出墓（冲墓）、被合→冲合、动化进退→临值/退神、独发→临值或临月建。引擎对每一法则各给出 ≤3 个候选公历日。

最近优先排序：所有类型的候选日先摊平为统一池，按公历日升序排列，最近一日即"首选应期"（前端「应期推导」面板顶部以 🎯 标出，并随卦象数据一并喂给 AI 引用，AI 不得自行推演日期）。

四类冲突 / 印证标注（只标注现象，不臆断吉凶；旺衰远近交由用神旺衰定夺）：

  • 多法并应（agreement）：同一公历日被 ≥2 种应期法则同时命中 → 多象同指，事象确凿，可信度高。
  • 远近两应（divergent）：近期型（出空/冲空实空/临值/冲合/独发临值）与远期型（出月实破/出墓/独发临月建）的最近候选相差 >40 天 → 近象远象并存，须察用神旺衰（旺相应近、休囚应远）定夺。
  • 卦反吟（unstable）：本卦变卦地支逐一相冲 → 事多反复，应期或迁延不定。
  • 用神受制（weak）：用神既真空又月破 → 应期当远，须出月出旬方应。
🔬 复核方法：展开「应期推导」面板，顶部 🎯 为最近优先裁决结果；若出现 📌 标注条，即对应上述四类信号之一，可按古法"旺相应近、休囚应远"进一步定夺。
