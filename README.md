# 增删卜易 · 六爻占卜系统

基于《增删卜易》的六爻占卜 Web 应用：铜钱摇卦 / 手动输卦双模式起卦，八宫纳甲排盘，断卦法度引擎（七步断卦链 + 五档吉凶），应期推导引擎，13 门类知识库，AI 释卦，原案例对照，万年历择吉。后端 AI 代理置于仓根 `functions/api/`（Cloudflare Pages 约定），全站自包含运行。

---

## 一、已实现功能总览

### 1. 起卦（双模式）
- **铜钱摇卦**：三枚铜钱六次模拟投掷，实时取真太阳时起卦。
- **手动输卦（复盘）**：逐爻选择四象（少阳/少阴/老阳/老阴），并手工填写起卦年/月/日/时四柱干支。**复盘须用原始起卦时辰——四项不填全无法排盘，系统不预填、不兜底当前时间**，确保复盘数据为真。

### 2. 排盘（八宫纳甲）
- 64 卦完整纳甲数据（浑天甲子，天干地支逐爻齐备），八宫卦序、世应、宫五行全部经逐卦校验。
- **六亲实时计算**（生我者父母、我生者子孙、克我者官鬼、我克者妻财、同我者兄弟），数据不写死。
- **六神依日干排定**（甲乙青龙、丙丁朱雀、戊勾陈、己螣蛇、庚辛白虎、壬癸玄武），自下而上顺排；手动输卦时依用户所选日辰排定。
- **伏神"降妖三式"**：定乾坤（取本宫首卦）→ 寻龙诀（查缺用六亲所在爻）→ 显真形（挂于飞神之下）。
- **变卦六亲铁律**：以本卦之宫五行为"我"。

### 3. 断卦法度引擎（排盘增强 R1）
- **六冲 / 六合卦标注**：八纯、天雷无妄、雷天大壮等六冲卦；地天泰、天地否等六合卦。
- **生旺墓绝十二宫**：按五行长生表标注每爻入墓 / 临绝。
- **回头生克与进退神**：动爻化出之爻对本爻的生克（回头生/回头克）、化进神/化退神。
- **反吟 / 伏吟**：卦变六爻地支相冲（反吟）、相同（伏吟）识别。
- **三合 / 三刑**：申子辰三合等，寅巳申三刑等。
- **独发 / 独静**：一爻独发、五爻独静识别。
- **太岁 / 岁破**：年支纳入旺衰维度（仅标注）。
- **纳音**：六十甲子纳音逐爻标注。
- **动散**：动爻逢日支冲为动散（如风吹火灭）。

### 4. 吉凶判定引擎（七步断卦链 + 五档）
- 按《增删卜易》断卦次序固化为**七步可解释规则链**：定用神 → 察旺衰 → 观动静 → 审世应 → 看忌仇神 → 察卦象 → 察门类。每一步输出「判据 / 结论 / 依据」，前端断卦面板逐条展示，AI 释文逐条引用。
- **五档综合结论**：大吉 / 吉 / 中 / 小凶 / 凶（按评分拉开档次，警示适度、不伤人）。
- **用神两现取舍链**：①舍闲取世 → ②舍静取动 → ③舍破取全 → ④舍空取实 → ⑤舍伤取安 → ⑥舍其休囚用其旺相。
- **婚姻用神按性别分流**：男占取妻财、女占取官鬼。

### 5. 应期推导引擎
- 按"应期总注"法则由卦象自动推导：旬空→出空/冲空实空、月破→出月实破/逢合、入墓→出墓（冲墓）、被合→冲合、化进退→临值/退神、独发→临值/临月建。
- **最近优先裁决**：全类型候选日摊平按公历升序，最近一日为"首选应期"。
- **四类标注**（只标现象、不臆断）：多法并应（同日多法则命中）、远近两应（近象远象跨度>40天，按"旺相应近、休囚应远"定夺）、卦反吟（事多反复）、用神受制（真空兼月破，出月出旬方应）。

### 6. 分类占断知识库（13 门类）
- 婚姻 / 学业 / 功名 / 求财 / 疾病 / 出行 / 行人归期 / 诉讼 / 失物 / 子嗣胎孕 / 家宅迁移 / 终身财福 / 趋避防灾。
- 每门含：用神规则、断法要点、应期要点、持世吉凶；用于用神自动推断并并入 AI 提示词。
- **入口把关**：所问之事须用门类固化词（如"功名/仕途/升职/求职/前程"），不规范用词系统明示"只能通解"、按常理泛论，不让用神跑偏。

### 7. 原案例对照（《增删卜易》原案库）
- 已收录 8 例不常见原案（两现章 / 月破章 / 旬空章 / 独发章），**逐字转录原文 + 标章句出处**。
- 同卦 + 同日辰 + 同月建命中时，释卦页弹「📜 原案例对照」卡，展示野鹤原断语与用神取法。

### 8. AI 释卦
- 双模型（千问旗舰 `qwen-max` 默认主力 / 千问备选 `qwen3.7-flash`），密钥存服务端环境变量，经 Cloudflare Functions 代理调用。
- **数据增强**：卦象（六冲六合/墓绝/进退/反伏/独发/三合三刑）、断卦链、应期裁决、门类知识全要素结构化并入提示词——**AI 只解读、不自行推演**。
- 输出固定首句 + 通俗断语 + 「专业详解」折叠；附断卦依据链 / 应期推导 / 原案例对照面板。
- **提示词与输出 XSS 加固**：用户输入经 HTML 转义后入 DOM，AI 文本先转义再渲染。

### 9. 时间体系（精确到秒）
- **子时换日**：晚子时（23:00 起）即起次日日柱，精确到秒——野鹤"神仙难断子时卦"由此而解。
- **月建遵节气（按时分）**：交节日前后不提前换月。
- **真太阳时**：万年历支持一键定位（经度校正 + 均时差公式），起卦可复用该时刻。

### 10. 万年历（特色功能）
- **一键定位 · 真太阳时**：自动定位经度（定位失败默认北京基准 116.46°E），以均时差公式 + 经度校正计算真太阳时，年月日时四柱干支按精确时刻排定，时辰不因时区失真。
- **干支五行全览**：公历 / 农历 / 干支四柱 / 月建 / 日辰 / 旬空 / 节气交节逐日呈现。
- **神煞与黄历**：驿马等神煞标注；吉神宜趋 / 凶煞宜避（天喜、天医、驿马等吉神，月建、土符等凶煞，各有权重）；十二建除；日冲。
- **择吉助手**：六维评分择吉（建除 / 吉神 / 凶煞 / 宜忌 / 日冲 / 用神旺衰），事项映射黄历宜忌（嫁娶、交易、入学、求医、出行、祭祀、置产），支持联卦模式以卦中用神旺衰加权；释卦页「此卦择吉」一键跳转定位。
- **应期反查**：依卦中用神地支反推未来 365 天内的应事之日，结果卡可一键返回释卦页。

### 11. 历史记录
- `localStorage` 本地存储，目录折叠式展示，含求卦者资料与 AI 解读回写。

## 二、目录结构

```
zsby/                                # 仓库根（Cloudflare Pages 项目根）
├── index.html           # 门户（导航至各功能页）
├── jiegou.html          # 起卦页（铜钱摇卦 + 手动输卦，双模式）
├── jiegua.html          # 释卦页（AI 解读 + 断卦/应期/原案面板）
├── wnl.html             # 万年历（真太阳时、择吉、应期反查）
├── history.html         # 占卜历史（localStorage，目录折叠式）
├── help.html            # 使用指南
├── ly/                  # 六爻排盘模块（五层架构）
│   ├── lunar.js         # 农历/干支/节气/旬空计算库
│   ├── shuju.js         # 【数据层】64 卦完整数据（纳甲天干地支）
│   ├── suanfa.js        # 【算法层】六亲/六神/伏神/断卦链/应期引擎/原案库
│   ├── zhukong.js       # 【主控层】摇卦/排盘/渲染/事件/手动输卦
│   └── yangshi.css      # 【样式层】古风排版、爻象绘制、响应式
├── api/
│   └── qwen.js          # 通义千问调用模块（双模型，密钥在服务端）
└── functions/
    └── api/
        └── ai.js        # AI 释卦代理（Cloudflare Pages 后端）
```

## 三、模块化架构（ly/ 五层职责）

| 层 | 文件 | 职责 |
|----|------|------|
| 结构层 | `jiegou.html` | HTML 容器 + 交互按钮，逻辑委托 `ly/` 模块 |
| 数据层 | `ly/shuju.js` | 64 卦原始数据（浑天甲子纳甲，六亲留空由算法算） |
| 算法层 | `ly/suanfa.js` | 排盘核心算法 + 断卦链 + 应期引擎 + 原案库，全部"实时计算"不写死 |
| 主控层 | `ly/zhukong.js` | 串联流程：取日干 → 排盘 → 渲染 → 绑定 → 跳转释卦 |
| 样式层 | `ly/yangshi.css` | 古风视觉、爻象绘制、六神配色、响应式三档 |

**关键算法约定**
- **六亲实时计算**：按五行生克动态得出（生我者父母、我生者子孙、克我者官鬼、我克者妻财、同我者兄弟）。
- **变卦六亲铁律**：变卦六亲以本卦之宫五行为"我"。
- **伏神降妖三式**：定乾坤 → 寻龙诀 → 显真形。
- **六神起法**：日干定初爻起点，自下而上顺排。

## 四、核心数据流

1. **起卦**：摇卦或手动输卦 → 同一 `completeAndDisplay()` 排盘 → 保存 `guaData`（本卦/变卦、世应、动变详情、六爻地支六亲、时间信息含四柱干支）至 `localStorage.currentGua`。
2. **释卦**：读取 `currentGua` → 构建 `guaInfo`（含手动输入的真实 `timeInfo`）→ 计算月破/日破/暗动/真空假空/墓绝 → 取用神 → 算断卦链 → 推应期 → 查原案 → 调用 AI。
3. **AI 解读**：`systemPrompt` 固化断卦口吻与六步框架；`userPrompt` 结构化传入全部已排定数据，**AI 只解读、不计算**。
4. **历史**：`localStorage.guaHistory` 目录折叠式展示。

## 五、模型说明

| 模型 | 服务端环境变量 | 实际模型名 | 页面标注 | 角色 |
|---|---|---|---|---|
| 千问旗舰 | `QWEN_API_KEY` | `qwen-max` | 千问旗舰 | 默认主力 |
| 千问备选 | `QWEN2_API_KEY` | `qwen3.7-flash` | 千问备选 | 备选 |

两模型提示词完全一致，解读风格与准确性统一。密钥存于 Cloudflare Pages 环境变量，前端经 `functions/api/ai.js` 代理调用，密钥永不进入前端代码。

## 六、依赖与存储

- `lunar.js`：农历/干支/节气/旬空计算库（完整 lunar-javascript 内嵌于 `ly/`）。
- API 密钥：`QWEN_API_KEY` / `QWEN2_API_KEY`（Cloudflare Pages 环境变量）。
- 数据存储：`localStorage`（`currentGua`、`userInfo`、`guaHistory`），仅本地浏览器。

## 七、技术约束（不可改动）

- `ly/suanfa.js` 排盘核心算法与断卦引擎（六亲实时计算、六神、伏神三式、变卦、断卦链、应期引擎、原案库）。
- `ly/zhukong.js` 主控流程（`completeAndDisplay`、`renderFinalResult`、`buildGuaHtml`）。
- `ly/lunar.js` 时间计算核心逻辑。
- `api/qwen.js` 的调用结构、`systemPrompt` 断卦口吻与断卦铁律。
- **时间体系口径**：晚子时换日（`getDayInGanZhiExact`）、月建按时分（`getMonthZhiExact`），全站统一，不可回退普通版。
